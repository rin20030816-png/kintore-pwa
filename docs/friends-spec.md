# 友達機能の仕様（確定版）

## 決まっていること
- 友達の追加は「招待リンク」。リンクは **1人だけ使えて、7日で切れる**。使った時点で、その場で友達になる（承認の待ち時間なし）。招待した人には、次にアプリを開いたときに知らせる。
- リンクの形: `https://kintore-pwa.pages.dev/f/<12文字>`（例: `/f/3f9a71c2b8d0`）。12文字は、推測できない乱数（16進数）。
- 友達は **最大30人**（今は固定）。友達はいつでもやめられる。ブロックできる（ブロックすると友達から消え、おたがいに見えず、招待も使えない）。
- **おたがいに「見せる」がONのときだけ**見える。初期設定はOFF。
- 友達に見えるのは「表示名」「行った日」「ポイント」だけ。メールアドレス・種目・重さ・回数・体重は見えない。
- 友達になれる条件: 表示名（1〜12文字）を決めていること。ログインが必要。
- ランキング: **週間 = 直近7日**、**月間 = 今月の1日から**。

## ポイントの計算（確定）
- **強度** ＝ そのセットの重さ ÷ その種目の「直近90日の最高の推定1RM」（推定1RMは、10回までのセットで計算）。強度は110%までで数える。
- **セットの点（強度ゾーン）**: 40〜59% → 5 / 60〜74% → 12 / 75〜84% → 20 / 85〜94% → 30 / 95%以上 → 40。40%未満は0。
- **回数ボーナス**: 8回以上、かつ強度95%未満のセットは ＋10。
- **ルール**: 1種目5セットまで（点の高い順）／強度95%以上は1日3セットまで／1日のセット合計は600ptまで（ボーナスは別）。
- **ベスト更新ボーナス**: MAX更新 ＋40 ／ RM更新 ＋10（MAX更新が出た日はMAX更新のみ） ／ 大台突破 ＋80。1種目につき1日1回ずつ。
- **ベスト作り**: 新しい種目は、最初の3日分の記録は点なし（4日目から対象）。
- **対象外**: 自重の種目・有酸素（当面）。
- 記録の入力は自己申告。

## データベース（`supabase/friends.sql`）
- 表: `profiles`（表示名・見せる）、`friendships`、`blocks`、`friend_invites`、`daily_points`（行った日・ポイント）。すべてRLSあり。
- 友達の関係・ブロック・招待は、**表を直接書けない**。書くのは、関数（`create_invite` `accept_invite` `remove_friend` `block_user` など）だけ。
- 友達の情報は、表を直接読ませず、`friends_activity()` 関数を通して渡す。関数が、友達であること・おたがいに「見せる」がONであること・ブロックがないことを確かめる。最長62日ぶんまで。
- アカウントを消すと、関係・ポイントも `on delete cascade` で全部消える。

## 確認したこと（37項目、すべて期待どおり）
友達でない人に見えない／表を直接読んでも自分の分だけ／他人のポイント・プロフィール・友達関係を書けない／内部関数を直接呼べない／相手か自分が「見せる」OFFなら見えない／ブロックされた人は招待を使えない／期限切れ・使用済み・自分の招待／未使用の招待は5本まで／友達30人の上限（相手がいっぱいでも、自分がいっぱいでも）／100日ぶんは取れない／アカウント削除で関連データも消える。
